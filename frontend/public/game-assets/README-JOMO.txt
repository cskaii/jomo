JOMO - SIMPLE ASSET GUIDE

Tilesets: repeat these to build your map.
  Grass = open ground. Water = water around your islands.
  LandEdges = land corners, straight shores, inner corners and center.
  Paths = dirt paths and stepping stones. Soil = planting ground.

Objects: place these on top of your ground.
  Plants and Trees = keep each plant's growth stages together.
  Decorations = bush, rock, mushroom, log and grass tuft.
  Fences = fence and gate. Bridges = wooden bridge.
  Buildings = cottage, shed and greenhouse.

Characters: each pet has its own folder.
  pet.png = original static image.
  pet-walk.png = four-direction movement sheet.
  Movement rows from top: down, up, left, right.
  Each row has 4 frames, read left to right; 150ms per frame.
  Each frame is 256x256; movement sheets are 1024x1024.
  Fish uses swimming movements instead of walking.
  Existing idle animation sheets have 4 columns and 2 rows.

Icons: Coins, Seeds and SeedPackets.
Backgrounds: the earlier sky/lawn backgrounds.

New individual map pieces are 256x256 PNGs. Land tile sheet is 768x768,
split into 3 columns and 3 rows. You can use the separate edge files instead.
Ground tiles fully fill their square; objects and pets have transparent backgrounds.
For a simple starting layout, copy map-preview.png. Use walking-preview.gif
to check the pet animations. The preview pictures are examples, not map tiles.

Original files already in this folder were kept. Use the named subfolders above
for the organised assets. No need to move the originals yourself.
